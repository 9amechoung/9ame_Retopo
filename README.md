# 9ame Retopo

zRail 스타일의 Maya 리토폴로지 도구입니다. 레일 두 개 사이에 쿼드 스트립을 만들고, 하이폴리 표면에 스냅하고, 엣지 루프를 추가하고, 브러시로 릴랙스할 수 있습니다.

- 대상: Maya 2022 이상 (Python 3, PySide2/PySide6)
- 구현: Python + OpenMaya 2.0, 모든 작업은 Ctrl+Z 한 번으로 되돌릴 수 있습니다.

## 설치

1. 이 저장소를 원하는 위치에 받아둡니다.
2. `nine_retopo_install.py` 를 Maya 뷰포트에 드래그 앤 드롭합니다.
3. 메인 메뉴바에 **9ame Retopo** 메뉴가 생깁니다. 다음 실행부터는 모듈 파일 `nine_retopo.mod` 로 자동 로드됩니다.

## 삭제 / 업데이트

- **삭제**: `nine_retopo_uninstall.py` 를 뷰포트에 드래그 앤 드롭하거나 **9ame Retopo → Uninstall** 을 누릅니다. 플러그인 언로드, 메뉴·창 제거, 모듈 파일 삭제까지 처리하므로 그 다음 폴더를 지우면 됩니다.
- **업데이트**: 언인스톨 → 기존 폴더 삭제 → 새 버전 폴더의 `nine_retopo_install.py` 드래그 앤 드롭. Maya 재시작은 필요 없습니다. 새 폴더의 `nine_retopo_install.py` 만 바로 드롭해도 이전 버전을 먼저 정리합니다.

## 사용법

| 기능 | 방법 |
|---|---|
| **Live Surface** | 하이폴리 메쉬 선택 → *Set From Selection*. 스냅 기준이 되고, `makeLive` 로 Maya 커브 툴도 표면에 붙습니다. |
| **Draw Rails** | zRail 방식 드로잉 툴입니다. 하이폴리 위에 드래그해서 레일을 그리면 두 번째 레일부터 스트립이 자동으로 생기고, 이후 레일은 직전 스트립 끝에서 계속 이어집니다. |
| **Build Strip** | 레일 2개 선택 → 버튼. 레일은 NURBS 커브(Live 상태에서 그린 커브)나 리토폴 메쉬의 엣지 체인 모두 가능합니다. |
| **Insert Edge Loop** | 엣지 하나 선택 → 링 전체에 루프 추가 후 새 버텍스를 표면에 스냅합니다. |
| **Relax Selection** | 버텍스/엣지/페이스/메쉬 선택 → 라플라시안 릴랙스 후 표면에 재투영합니다. |
| **Snap To Surface** | 선택한 버텍스를 표면으로 투영합니다. |
| **Relax Brush** | 리토폴 메쉬 선택 → 활성화 → 뷰포트에서 드래그합니다. 반경은 월드 단위입니다. |

### Draw Rails (zRail 방식)

1. 하이폴리를 Live Surface로 설정합니다.
2. **Draw Rails**를 누르고 뷰포트에서 하이폴리 위에 드래그합니다.
   - 첫 번째 스트로크는 노란 가이드 레일로 남습니다.
   - 두 번째 스트로크부터는 그리는 동안 **초록색 반투명 스트립 미리보기**가 실시간으로 따라옵니다. 놓는 순간 실제 스트립이 생깁니다.
   - 계속 그리면 직전 스트립의 끝 엣지에서 이어지고(연장), 하나의 메쉬로 웰드됩니다.
   - 기존 리토폴 메쉬의 **아무 테두리 변 옆에** 그려도 그 변에서 자라납니다. 예를 들어 스트립 끝(빨간 짧은 변) 옆에 나란히 선을 그으면 스트립이 옆으로 늘어나고, 긴 변(파란 변) 옆에 그으면 그쪽으로 이어집니다. 어느 변에서 이어질지는 그리는 동안 초록 미리보기로 보이고, 가장 가까운 변이 선택됩니다.
3. **Shift + 드래그**로 그리면 새 체인을 시작합니다. 버튼 **New Chain**도 같은 동작입니다. 이때 다음 한 획은 기존 메쉬 옆이라도 붙지 않고 새 가이드 레일이 됩니다.
4. **Ctrl + 드래그**로 리토폴 메쉬 위를 훑으면 커서 아래 엣지 링을 따라 **하늘색 컷 라인**이 실시간으로 미끄러지고, 놓는 위치에 엣지 루프가 추가됩니다(면 쪼개기). 새 버텍스는 하이폴리 표면에 붙습니다. 체인 끝 엣지를 가로지르게 잘라도 다음 스트립이 그대로 웰드됩니다.
5. 기존 리토폴 메쉬에서 이어 그리려면 테두리 엣지를 선택한 상태에서 Draw Rails를 켭니다.
6. 시작점과 끝점이 가까운 스트로크는 닫힌 레일로 처리됩니다. 닫힌 레일 두 개를 그리면 원통형 스트립이 됩니다.
7. Ctrl+Z는 스트로크(또는 컷) 단위로 되돌립니다. 되돌린 뒤 이어 붙이기가 어긋나면 New Chain으로 새로 시작하세요.

#### 테두리 편집 (ziRail 단축키)

Draw Rails 툴이 켜진 상태에서 리토폴 메쉬의 열린 테두리를 골라 편집합니다. 선택한 테두리는 주황색 선으로 표시됩니다.

| 조작 | 동작 |
|---|---|
| **Ctrl+Shift+클릭** 두 번 | 첫 버텍스에서 두 번째 버텍스까지 테두리를 선택합니다(짧은 쪽으로). |
| **Ctrl+Shift+더블클릭** | 그 테두리 전체를 선택합니다. |
| 그냥 클릭 (드래그 없이) | 테두리 선택을 해제합니다. |
| 테두리 선택 후 **Ctrl+드로우** (빨강) | 선택한 테두리의 버텍스를 새 획을 따라 고르게 다시 배치합니다. |
| 테두리 선택 후 **Shift+드로우** (파랑) | 선택한 테두리를 획을 따라 돌출해서 연장합니다. 그리는 동안 초록 미리보기가 보이고, 돌출 후에는 새 끝 테두리가 선택된 상태로 남아 계속 늘릴 수 있습니다. 분할 수는 Spans across(0이면 정사각형 쿼드)를 따릅니다. |
| 테두리 2개 선택 후 **Ctrl+가운데 클릭** | 두 테두리 사이를 쿼드로 이어(브리지) 하나의 메쉬로 붙입니다. 두 테두리의 엣지 수가 같아야 합니다. |
| 테두리 2개 선택 후 **Shift+가운데 클릭** | 두 테두리를 가운데로 모아 버텍스끼리 붙입니다(웰드). |
| **Ctrl+가운데 드래그** (선택 없이) | 버텍스에서 다른 버텍스로 끌어다 놓으면 그 위치로 옮겨 붙입니다(타겟 웰드). 끄는 동안 초록 선으로 대상이 표시됩니다. |

- 테두리 선택이 있을 때 Ctrl+드래그는 다시 그리기가 되고, 선택이 없을 때만 엣지 루프 컷이 됩니다. Shift도 마찬가지로 선택이 있으면 돌출, 없으면 새 체인입니다.
- 버텍스는 화면에서 커서 근처(20픽셀 안)의 것을 집습니다. 다른 메쉬끼리 브리지/웰드하면 하나의 메쉬로 합쳐집니다.
- 이 편집을 한 메쉬는 레일만으로 다시 만들 수 없어서 Spans along/across 숫자 변경 대상에서 빠집니다.

#### 그린 뒤에 분할 수 바꾸기

- **Spans along (rail)** (파란 표시): 레일 방향, 즉 그린 선을 따라가는 분할 수입니다. 체인 전체에 공통으로 적용됩니다.
- **Spans across** (빨간 표시): 두 레일 사이의 분할 수입니다. 체인의 모든 스트립에 적용됩니다. `0`(기본값)이면 정사각형에 가까운 쿼드가 되도록 자동으로 정합니다.
- 값을 바꾸면 **지금 그리고 있는 체인**, 또는 **선택한 체인 메쉬**가 같은 레일로 바로 다시 만들어집니다. 다시 만든 뒤에도 이어 그리기가 그대로 웰드됩니다. Ctrl+Z로 되돌릴 수 있습니다.
- 체인 메쉬를 선택하면 툴 창의 숫자가 그 체인의 값으로 바뀝니다.
- 레일 정보는 메쉬의 `nineRetopoChain` 속성에 저장되므로 씬을 저장했다 열어도 수정할 수 있습니다.
- Ctrl+드래그로 손으로 자르거나 스트립 끝 같은 다른 변에서 옆으로 늘린 메쉬는 레일만으로 다시 만들 수 없어서, 이후에는 숫자로 바꾸는 대상에서 빠집니다. 그때부터는 Ctrl+드래그로 선을 추가하세요.

#### 화면 표시

- 리토폴 메쉬는 플러그인의 `nineRetopoOverlay` 로케이터가 **하이폴리 위에 항상 겹쳐서** 그립니다. 카메라를 향한 면만 반투명 보라색 면, 하늘색 와이어, 흰 점으로 표시해서 표면에 붙어 있어도 묻히지 않습니다. 그리는 중의 미리보기는 초록색으로 표시됩니다.
- 오버레이는 선택되지 않고 아웃라이너에도 숨겨져 있습니다. 메쉬를 지우면 다음 작업 때 같이 정리되고, 언인스톨하면 모두 삭제됩니다.
- 리토폴 메쉬 자체에는 반투명 보라색 셰이더(`nineRetopo_mtl`)도 들어갑니다.
- Draw Rails 툴이 켜져 있는 동안에는 선택된 오브젝트의 와이어프레임을 전부 그리도록(`displayPref -wireframeOnShadedActive full`) 바꾸고, 툴을 바꾸면 원래 설정으로 돌려놓습니다.
- **Retopo Look On/Off** 버튼: 선택한 메쉬의 리토폴 표시를 켜고 끕니다. 끄면 오버레이와 셰이더가 빠지고 기본 회색(`lambert1`)으로 돌아가며, 그 메쉬에서는 Ctrl+드래그 컷과 테두리에서 늘리기도 하지 않습니다. 이 플러그인으로 만들지 않은 메쉬도 켜면 같은 기능을 쓸 수 있습니다.
- **Show overlay** 체크박스: 모든 오버레이를 한 번에 숨기거나 보입니다. 메쉬와 셰이더는 그대로입니다.

옵션(Spans along / Spans across / Stroke smoothing)은 툴 창의 Rail Strip 그룹에서 바꿉니다. Spans along이 `0`이면 첫 스트립은 정사각형에 가까운 쿼드로 나누고, 이어지는 스트립은 앞 스트립과 같은 분할 수를 씁니다.

### Build Strip 옵션

- **Spans along**: 레일 방향 분할 수입니다. `0` 이면 자동으로 정해집니다. 엣지 레일이 있으면 그 엣지 수에 맞추고, 없으면 정사각형에 가까운 쿼드가 되도록 계산합니다.
- **Spans across**: 두 레일 사이 분할 수입니다.
- **Merge into edge rail mesh**: 엣지 레일을 쓴 경우 새 스트립을 해당 메쉬에 합치고 버텍스를 웰드합니다. 기존 메쉬에서 이어서 확장하는 작업 흐름입니다.
- 닫힌 레일 두 개(예: 원형 커브 두 개, 닫힌 엣지 루프 두 개)를 고르면 원통형 스트립이 만들어집니다.
- 노멀은 Live Surface 바깥쪽을 향하도록 자동으로 정렬됩니다.

## 구조

```
nine_retopo_install.py      드래그 앤 드롭 설치
nine_retopo_uninstall.py    드래그 앤 드롭 삭제
plug-ins/nineRetopo.py      플러그인 (메뉴 등록, 리토폴 오버레이 노드)
scripts/nine_retopo/
  geometry.py               Maya 비의존 기하 계산 (리샘플, 정렬, 그리드, 릴랙스)
  mesh_utils.py             메쉬 읽기/쓰기, 선택 처리, undo
  surface.py                Live Surface 와 투영
  strip.py                  레일 → 스트립
  rail_tool.py              zRail 방식 레일 드로잉 툴 (draggerContext)
  viewport.py               화면 좌표 → 메쉬 레이캐스트
  loops.py                  엣지 루프 삽입, 커서 위치 링 컷
  display.py                리토폴/미리보기 셰이더, 오버레이 연결, 와이어프레임 표시
  chain.py                  그린 체인의 레일 저장과 분할 수 변경 시 다시 만들기
  border_ops.py             테두리 선택, 다시 그리기, 돌출, 브리지, 웰드, 타겟 웰드
  relax.py                  릴랙스
  brush.py                  뷰포트 릴랙스 브러시 (draggerContext)
  ui.py                     도킹 가능한 툴 창
tests/                      geometry 단위 테스트
```
